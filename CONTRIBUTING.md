# Contributing

Thanks for helping improve **Free Dev Resources**.

The goal of this repository is to maintain a practical, verified collection of free tiers, credits, student offers, startup programs, AI APIs, cloud services, databases, and developer tools.

## Before submitting a resource

Please make sure the resource:

- Is useful to developers, builders, students, or startups.
- Has an official free tier, free credits, free trial, student benefit, startup program, or open-source benefit.
- Does not rely on fake accounts, leaked credentials, bypasses, abuse, or unsupported workarounds.
- Links to an official provider page whenever possible.
- Includes clear limitations when relevant.

## Resource format

Use this structure when adding a resource:

```md
### Resource Name

Short description of what the service does.

- **Offer:** What is free
- **Type:** 🆓 Free Tier / 🎁 Free Credits / ⏱️ Trial / 🎓 Student / 🚀 Startup
- **Card required:** Yes / No / Unknown
- **Commercial use:** Allowed / Restricted / Unknown
- **Official link:** https://example.com
- **Docs / pricing:** https://example.com/docs
- **Last verified:** YYYY-MM-DD
- **Notes:** Important limits, eligibility, or caveats
```

## Verification rules

Prefer official pricing, documentation, program, or product pages. Avoid relying only on blog posts, social posts, or third-party lists for claims about credits and limits.

If an offer cannot be verified, mark it clearly as unverified instead of presenting it as confirmed.

## Updating existing entries

Free tiers change often. If you notice that an offer is outdated:

1. Update the limit or eligibility details.
2. Replace outdated links if necessary.
3. Update the `Last verified` date.
4. Mention the change in the pull request description.

## Pull requests

Keep pull requests focused. Adding or updating a small group of related resources is easier to review than mixing many unrelated changes.

By contributing, you help keep this repository accurate and useful rather than simply large.
