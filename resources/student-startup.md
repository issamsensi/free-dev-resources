# Student & Startup Programs

Curated programs that provide free developer tools, cloud credits, infrastructure, or other benefits to eligible students and startups.

> Last reviewed: **2026-08-18**. Eligibility rules, credit amounts, and partner offers change frequently. Always confirm the current terms on the official program page.

## Student Programs

### GitHub Student Developer Pack

A large collection of developer tools and partner offers for verified students.

- **Offer:** GitHub Pro plus rotating partner benefits and developer offers
- **Type:** 🎓 Student
- **Eligibility:** Verified students
- **Official link:** https://education.github.com/pack
- **Last verified:** 2026-08-18
- **Notes:** Individual partner offers can change independently of the Pack itself.

### Microsoft Azure for Students

Azure program designed for eligible students to experiment with cloud services without starting on a standard paid subscription.

- **Offer:** Student cloud credits and selected free services
- **Type:** 🎓 Student
- **Official link:** https://azure.microsoft.com/free/students/
- **Last verified:** 2026-08-18
- **Notes:** Check regional eligibility and current credit amount on the official page.

### Sentry for Education

Education-focused access to Sentry for eligible students and educational use cases.

- **Offer:** Education benefits and extended access for eligible users
- **Type:** 🎓 Student / Education
- **Official link:** https://sentry.io/for/education/
- **Last verified:** 2026-08-18

## Startup Programs

### AWS Activate

AWS program that provides eligible startups with cloud credits, technical support, training, and partner benefits.

- **Offer:** AWS credits based on eligibility and program tier
- **Type:** 🚀 Startup
- **Official link:** https://aws.amazon.com/startups/credits
- **Last verified:** 2026-08-18
- **Notes:** Credit amounts depend on startup stage, provider affiliation, and other eligibility criteria.

### Google for Startups Cloud Program

Cloud and AI benefits for eligible startups building on Google Cloud.

- **Offer:** Google Cloud credits with different tiers for eligible startups, including dedicated AI-focused benefits
- **Type:** 🚀 Startup
- **Official link:** https://cloud.google.com/startup
- **Last verified:** 2026-08-18
- **Notes:** Credit levels and eligibility vary by startup stage and program track.

### Microsoft for Startups

Microsoft program offering eligible startups access to Azure, AI, developer tools, and other benefits.

- **Offer:** Azure and developer benefits based on program eligibility
- **Type:** 🚀 Startup
- **Official link:** https://www.microsoft.com/startups
- **Last verified:** 2026-08-18

## General Cloud Credits

### Google Cloud Free Program

Google Cloud offers a new-customer trial plus an Always Free-style selection of usage allowances on selected products.

- **Offer:** New-customer cloud credits plus free usage allowances on selected products
- **Type:** 🎁 Free Credits / 🆓 Free Usage
- **Official link:** https://cloud.google.com/free
- **Last verified:** 2026-08-18
- **Notes:** Trial credits expire and require checking current eligibility and billing terms.
